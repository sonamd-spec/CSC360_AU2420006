## Notes



### Connection Between Programming and Mathematics



In this session, I learned more about the basics of Computer Graphics. What interested me most was that there is a strong connection between programming and Mathematics in terms of graphics. While I previously saw Mathematics and programming as completely separate subjects, I now know that the mathematical concepts are used to help the computer know what and where to draw certain objects.



For instance, when we need to plot a point or a line, the use of coordinates helps position whatever is being plotted on a specific location on the screen. These coordinates take the form of values that are fed to the computer via code, and they enable it to plot whatever needs to be drawn on a specific location. Thus, these insights helped me understand why it is important to have an understanding of Mathematics in Computer Graphics.



### Geometric Primitives



I also enjoyed the discussion on geometric primitives such as points, lines and triangles. These primitives are the basis of what defines computer graphics. For instance, a point defines a location, and lines can be formed by connecting two points.



Triangles on the other hand can be defined using three points. This insight was very edifying as it helped me learn that a lot of complex graphics that one can think of are simply formed using points, lines and triangles.



### Creating and Moving Shapes



Another interesting activity that we did was to create the various primitive shapes using code. We were also tasked to come up with a way of making the shapes move. What this taught me is that the location of any object on a screen is not fixed, but it can be changed by simply changing the values used for the coordinates.



By manipulating these values, one can make it possible to move any object on the screen. Thus, I learned that in order to make something move on a screen, one needs to develop some logic that can help change the values of the coordinates.



### Static and Interactive Graphics



The lecture on static and interactive graphics was also very insightful. Static graphics are simply graphics that are fixed. This means that they do not change with respect to the user’s actions. On the other hand, interactive graphics mutate depending on either the user’s requests or other graphics.



This was very informative to me as it allowed me to know what I have been encountering previously when I use interactive graphics. I now realize that the art of programming is used to make the graphics interactive by making it possible for them to change depending on certain conditions.



### SSH, HTTPS and GitHub



The last set of notes that I found very interesting was the discussion on SSH and HTTPS and their relationship with GitHub. Interestingly, I learned that both protocols can be used to connect and manage a repository on GitHub.



While learning about SSH and how it connects to GitHub, we also learned about public and private keys. The main message that I got while learning this was that the public key is added to GitHub while the private key is used to access it.



This was very new to me as I always assumed that the two were connected using the private keys. Furthermore, these insights helped me understand how GitHub is able to provide a secure environment for managing code repositories while working with an underlying protocol that is based on public and private keys.
