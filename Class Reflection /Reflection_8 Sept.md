Events and Graphics



In the previous class, we discussed how events are related to graphics. An event can simply be described as something that happens as a result of any interaction the user has with the application. For example, the user can click a button, move the mouse, or type a key; all of these can result in events.



These events are important in graphics because they make the application interactive.



User Action Event Possible Response



Click a button Button event Perform an action



Move the mouse Mouse event Move or change an object



Press a key Keyboard event Perform a specific task



Change a value Value change event Update something on the screen



For example, if there is a Start button in a Game and the user clicks the Start button, the game will begin. In this example, the event occurred as a result of the user clicking the Start button and the response was for the game to begin. This helped me understand that a graphical application can be made interactive by associating events with graphical components.



Event Handling



After discussing events, we then discussed event handling. Event handling simply means deciding what should occur once a certain event has occurred.



User Action → Event → Event Handler → Response



For example, when we click a button, the program detects the click and the event handler tells the program what action needs to be performed. A real-life example can be a lift. When we press the button for a certain floor, pressing the button is the event and the lift going to that floor is the response. Similarly, in a graphical application, the program responds according to the event performed by the user. I find this topic useful because it helped me understand how applications are made interactive instead of being just informative.



View and Wrapper



We also discussed the view and wrapper. I understood that view deals with what is displayed on the screen. A wrapper helps in wrapping or containing a certain component.



For example, a screen that contains a button, text field and slider requires a proper organization. Using a suitable structure helps us organize these components and makes the interface understandable. I found that while creating a graphical application, we also need to think about the manner in which different components are organized.
