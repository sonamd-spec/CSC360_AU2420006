## Understanding of the Basic Shapes



Before this class, I always thought that generating a shape on a computer is as simple as instructing it to do so. However, after learning the concepts behind it, I realized that a particular set of instructions must be provided to generate a certain object



For instance, for drawing specific objects like lines, circles, rectangles, etc., one must provide the necessary attributes.



For example, for a line, one must provide the coordinates for the starting and the ending points.



But how does the computer know what shape I want to draw? These basic questions were clarified in this class, where I learned that different shapes have specific attributes that one must enter in terms of numbers.



## Understanding the Concepts of Lines and Coordinates



The discussion about the lines helped me understand what coordinate system means. For a line, one has to provide two points. For these points, there should be a specific value for the x-axis and the y-axis. By changing these values, one can change the position, direction, length, and location of the drawn line



One example that I liked and understood was that by entering the same coordinates as both the starting and ending points, one can generate a zero-length line. It helped me connect the dots about how points and distances are related in mathematics to graphics.



## Learning About the Thickness and Apearance of Line



We were told that by altering specific properties of the drawn line, one can change how it looks. Some of these properties include the thickness of the line. I understood that by changing the value of such attributes, one can obtain completely different visuals of the drawn object



For instance, two lines with the same starting and ending points but different thicknesses will look completely different. By providing the same coordinates, one can also generate completely different shapes. Thus, it is critical to think about what we want to draw before attempting to do so.



The various attributes that one can change for a drawn figure are as follows:



Thickness, size, position, width, height, and radius.



## Understanding 2D Shapes and Coordinates



One of the most important lessons for this class was understanding 2D shapes and coordinates.



By using a coordinate system, where the x-axis and y-axis are changed, we can dictate how a certain graphics will be displayed. We can move an object left or right, up or down, stretch it, shrink it, and much more by changing these coordinates. It helped me relate what we learned with actual mathematics and how changing a few values can drastically change the outcome of the drawn shape



Some of the attributes that we can change for 2D shapes are as follows:



X and Y coordinates - which determines the position of the object



Width, height, and radius - which determines the size of the object

## Relationship Between Math and Graphics



This entire class made me realize why we needed to learn the concepts of math before actually jumping into the field of computer graphics. Most of the concepts that we learned in this class are inspired from mathematics.



For instance, points, coordinates, length, radius, width, height, dimensions, etc., are all mathematical concepts. It helped me grasp the big picture of how computer graphics functions on the basis of mathematics.



For instance, when I draw a line or a circle on a computer, the computer basically does not understand it as a line or a circle. Instead, it understands it in terms of the attributes that we discussed earlier.



## Understanding the Logical Aspect Behind Graphics



One of the most important things that I realized about graphics is that one must understand the logic behind generating figures before one actually tries to implement it in code. For instance, if I want to draw a line, I should ask myself questions like where shall I draw it, what shall be the thickness of the line, and where shall I draw it on the screen? Similarly, if I want to draw a circle, then I need to think about its center, radius, and location on the screen. Such logical thinking can help one save time and energy when it comes to actually programming it.
