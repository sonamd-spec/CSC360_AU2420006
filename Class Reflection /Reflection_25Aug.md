## Computer Graphics and Trees



In this class we continued reviewing our understanding of Computer Graphics and I learned how different objects can be represented and created through programming. We discussed example such as squares or triangles and trees. I learned that if I want to create a bigger graphic, I can break it into parts and focus on each piece.



We also discussed about tree, where tree in programming is not only something that we draw. A tree can mean a structure where different elements are connected to each other. We discussed parent and child relationships where one element can have elements connected below it. This gave me a basic understanding of how hierarchical structures work.



Another thing discussed was image analysis. We were introduced to ImageJ, which can be used to work with and analyse images. This helped me understand that computer graphics can not only involve creating graphics, but also analysing images.



## Maven and pom.xml



A major part of the class was about Maven and how it helps manage a Java project. I learned that Maven can handle lot of tasks that I would do manually.



We discussed the pom.xml file, which is an important file in a Maven project. The pom.xml file contains information about the project and helps the Maven understand what dependencies and settings are needed. I understood dependencies are additional libraries or tools that our project may need to run properly.



We also went through different stages of the Maven build process. The basic idea I understood was that Maven checks the project, compiles the source code, runs tests and can then package the project. The clean command can be used to remove files that were previously generated, so that the project can be built again.



This made me realise that there is a proper process behind building a java project instead of just writing the .java code and running it.



## Java Project Files and target Folder



We also discussed about different types of files that we see inside a Java project. Earlier, I mainly focused on the .java file because that is where we write our code. In this class, I learned that other files are also created during development and build process.



For example, the .java file has the source code written by the programmer, while the .class file has the compiled version of that code. We also talked about the .xsd file and the target folder.



The target folder contains files that were generated during the Maven build process. Understanding this was useful because sometimes I see a lot of folders and files in a project and I don't understand why they are there. Now, I have a better idea about which files are written by us and which ones are generated by the build process.



## GUI and Java Swing



Another interesting topic from the class was about GUI, or Graphical User Interface. We discussed how Java can be used to create interfaces that people can interact with. We were introduced to Java Swing and some of its components.



We looked at components such as buttons, panels and lists. I understood that these components are used for different purposes in an application. For example, a button can be used to perform an action when the user interacts with it, while a panel can be used to organise different components.



This helped me understand the basic structure of a GUI and how programming can be used to create something that a user can interact with instead of only working with the code in the background.



## Accessibility



We also discussed about accessibility while learning about GUI. I understood that when designing an application, we should think about different types of users and not only about how the interface looks.



One example we discussed was about alternative text for images. Alt text can provide information about an image when it can't be seen and can also help users who use screen readers. This made me realise that a good interface should not only work properly, but it should also be easier for different users to understand and use.



## Processes, Threads and Multithreading



Towards the end of the class, we learned about processes and threads. I understood a process as a running program, while a thread is a smaller unit of execution that is inside that process.



We discussed about the differnce between single-threaded and multithreaded programs. In a single threaded program, tasks generally follow one main path of execution. With multiple threads, more than one task can make progress within the same program.



The concept of multithreading was new and interesting to me because it explained how a program can handle different tasks without everything depending on one single sequence of execution.



## Thread Safety



We also discussed about thread safety and why it becomes important when multiple threads are working with the same resource. If different threads try to access or change the same thing, it can sometimes lead to unexpected results.



This was especially useful to understand in the context of GUI programming because the different parts of an application need to be handled carefully when working with threads. I understood that multithreading can make an application more responsive, but it also needs proper control so that different threads don't create problems.
