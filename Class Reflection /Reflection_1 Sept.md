Understanding our group projects



While I have better understood our group projects during the class, I initially understood the topic that had been given to our group, yet I was not clear what we were expected to create and what the features should be. Group 5 project



The project of Group 5 is about creating a JavaFX program that draws arrows between two lists that have common elements. I have understood that the first part of the program is about finding the elements that are present in both lists.



For example:



List 1: A, B, C, D



List 2: B, D, E, F



The common elements are B and D. The program should display the two lists on the screen and show the relationship between the matching elements using arrow.



I have understood that the project has a logical and graphical part. The logical part is to find the common elements and graphical part is displaying the lists and drawing the arrows between the correct elements.



Features that I understood for Group 5



During the thinking process, I have understood that some of the features that can be added are:



Feature What it does



Two Lists Allow two sets of elements



User Input Allow values to enter the lists



Common Element Checking Find the elements that are present in both lists



Graphical Display Display the lists on the JavaFX screen



Arrows Connect the matching elements



Clear Layout Make relationships between lists easy to understand



The interesting part is that the program needs to know where each element is placed so that the arrow can connect the correct elements.



Our group 6 project



Our project is to create a JavaFX program with a custom splash screen, using FXML. I have understood that a splash screen is the screen that is displayed when an application is started before the main application is opened.



The purpose of our project is to create our own custom splash screen instead of a basic or default opening screen. It should appear for a short time and then be taken to the main Java application.



Information on the Splash Screen



One of the main things I have understood is that we need to decide what information should be displayed on the splash screen.



The important information can include:



Application name



Applicant or student name



Student ID



A suitable design or logo



Loading or starting message if required.



The information should be arranged properly to avoid the screen to look crowded. As the splash screen will only be visible for a short time, the important information should be easily noticeable.



Design and Colour



I have also understood that the appearance of the splash screen is also a part of the project. We need to decide the background colour, text colour, font and the overall layout.



I think the colours should be decided in a way that the text is clearly visible. The design should be simple and clean rather than adding too many elements.



We can also use a small logo or a graphical element to make the splash screen look more like a real application. At the same time, the design should not distract for the main information.



Delay Time



Another important feature of our splash screen is the delay time. The splash screen should not stay on the screen permanently. It should appear while the application is starting, and then the main application should be opened after a short delay.



The basic flow that I have understood is:



Splash Screen



↓



Short Delay / Loading



↓



Main Application



The timing needs to be decided carefully. If the splash screen disappears too fast, the user may not able to read the information. If it stays too long, then the application feels slow.



JavaFX and FXML



I have also understood why JavaFX and FXML are being used in our project. JavaFX will help us to create the graphical application, while FXML can be used to design and organise the user interface.



The splash screen will need to be connected with the Java code so that it appears when the application is started. After the required delay, the splash screen should close and the main application should be opened.



This helped me understand that our project has a design part and a programming part.



Planning before Coding



The main thing that I have learnt from the project discussion is that we should not directly start to write the complete code. Firstly, we need to make a basic plan.



For our project, we can first decide the design of the splash screen, information that we want to show, colours and layout, and delay time. After that, we can create the FXML design and connect it with the Java code.



Similarly, understanding the requirements first will help us to divide the project into smaller tasks and work on them one by one.
