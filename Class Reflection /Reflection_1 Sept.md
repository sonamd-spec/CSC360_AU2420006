### Group 5 Project – Two Lists and Arrows



The Group 5 project is about making a java program that draws arrows between two lists with common elements. I realized from the discussion that the main point is, given two lists, to identify the common elements.



For instance, if the first list is A, B, C, and D and the second list is B, D, E, and F, the common elements are B and D. The program then has to identify these elements and depict them using arrows.



I found this project interesting as it combines regular programming logic with JavaFX graphics. The program has to first process the two lists and identify the common elements. The JavaFX interface then has to display the lists and also draw arrows between the common elements.



### Group 6 Project – Custom Splash Screen



Our Group 6 project is about making a splashscreen using JavaFX with FXML. From our discussion, I understood that a splash screen is a special screen that usually shows up for a short time when launching an application before the actual application is launched.



The aim of our project is to develop a custom splash screen and connect it well to the main Java application. This means that the splash screen has to be nicely designed and also well programmed. It also has to have some information, and we have to make sure that it transitions to the main application after a given time.



This discussion made me realize that we have to put effort into both the design and function of the splash screen.



### Information on the Splash Screen



We were able to discuss what information should be on our splash screen. The application name has to be visible so that the user knows what application is about to be launched. We also have to put in the applicant name and ID information.



I realized that these details should be organized on the splash screen instead of randomly putting them on the screen. Since the splash screen will only be visible for a short time, it is important to organize the information in such a way that the important data will be seen first. Moreover, we can also incorporate some nice graphics that will also let the splash screen look like a real application.



### Design and Colour Selection



Another thing that I realized from the discussion is the design and colour selection. We have to determine the background colours, text colours, font, the position of the information, etc.



The colours have to be pleasing to the eye; most importantly, the text has to be readable. I think the design should be as simple as possible since the main aim of the splash screen is to give out information while the application is starting. We should also avoid unnecessary features to make the splash screen look less cluttered.



### Delay Time and Loading



The delay time of our splash screen was also one point of discussion. The splash screen has to remain visible for a certain amount of time before transitioning to the main application. I realized that this time should be long enough for the application to be well loaded; however, it also should not be too long that the user is bored waiting for the application.



The general idea is that:



Splash Screen



↓



Short Delay / Loading



↓



Main Java Application



This means that the splash screen should be visible for long enough for the user to see the information and also to let the main application be loaded. If the delay time is too short, the user might not have enough time to read the information, and if it is too long, the user might get bored.



This discussion made me realize that even the smallest detail in an application such as the splash screen delay time has to be considered before launching the application.



### JavaFX and FXML



Since JavaFX and FXML are going to be used to build our splash screen, I also realized how these two can be used together. FXML allows for the creation of nice interfaces while JavaFX allows for proper programming of the interface.



In our project, we have to design our splash screen using FXML while also programming it using Java. The Java program will have to first show the splash screen and then load the main application after the delay time has been reached. The combination of FXML and Java will also help make the project organized.



### Planning Before Starting the Code



One major thing that I realized from the discussion is the importance of planning before writing any code.



We have to first know what we are doing and what we have to do before writing any code. For our project, we first have to lay out the information that we want to put on the splash screen. We also have to decide how the splash screen will look like using FXML and then actually program the splash screen using Java. Lastly, we have to connect the splash screen to the main application. These steps will help us plan the development of our splash screen project.
