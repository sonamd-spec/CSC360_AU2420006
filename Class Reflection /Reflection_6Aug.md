
# Reflection – CSC360 Session 1

In the first class, I got introduced to the basic idea of **Computer Graphics**. Before this class, I mainly thought computer graphics was just about creating attractive pictures on a computer. After learning about the topic, I understood that there is much more behind an image. A computer needs to store, represent and process the information of an image.

## Understanding Digital Images

One of the first things I learned was how a computer represents a digital image. An image can be divided into small parts called **pixels**, and these pixels can be arranged in the form of rows and columns. We can think of this arrangement like a matrix, where every position stores some value. For a colour image, these values can contain RGB information.

This made me understand that an image is not simply a picture but also a collection of information that a computer can work with.

## Raster and Vector Graphics

Another important topic was **raster and vector graphics**. I understood that raster graphics are made from pixels, so they are commonly used for photographs and normal digital pictures. If we enlarge a raster image too much, the individual pixels may become visible and the image can look less clear.

Vector graphics are different because they use shapes and mathematical information instead of depending completely on pixels. They are useful for things like logos, diagrams and drawings. The comparison helped me understand why a photograph and a logo can be represented differently.

| Raster Graphics                | Vector Graphics                                |
| ------------------------------ | ---------------------------------------------- |
| Made using pixels              | Made using shapes and mathematical information |
| Good for photographs           | Good for logos and diagrams                    |
| Can lose quality when enlarged | Can be resized more easily                     |
| Pixel-based                    | Shape-based                                    |

## Java Graphics

I also learned how **Java can be used for creating graphics**. Some of the important parts introduced were `JFrame`, `JPanel` and the Graphics Context.

I understood it in a simple way: `JFrame` provides the main window, `JPanel` gives an area where we can display things, and the Graphics Context provides the methods required for drawing. This gave me an idea of how a basic graphical program is organized in Java.

## Geometric Transformations

The topic of **geometric transformations** was interesting because it showed how objects can be changed on the screen.

The three main transformations I learned were:

* **Translation** – moving an object from one place to another.
* **Scaling** – increasing or decreasing the size of an object.
* **Rotation** – turning an object around a fixed point.

| Transformation | Simple Meaning |
| -------------- | -------------- |
| Translation    | Move           |
| Scaling        | Resize         |
| Rotation       | Turn           |

The examples involving a moving triangle and zooming helped me understand these concepts better. Instead of only remembering definitions, I could relate them to something that can actually happen in a graphical application.

## Lines and Intersection

I also learned about drawing lines, perpendicular lines and finding the **intersection point** of two lines. This showed me that mathematical concepts such as coordinates and equations are also useful in computer graphics.

## Git and SSH

Another part of the session was an introduction to **Git and SSH**. I understood that Git is useful for keeping track of changes in code, while SSH can be used for secure communication between computers. These are useful tools when working on programming projects.

## My Learning from the Class

Overall, the class gave me a basic understanding of what happens behind the graphics that we see on a computer. I learned that pixels, coordinates, shapes and mathematical operations are all connected to graphics programming. The topics that interested me the most were raster and vector graphics and geometric transformations because I could connect them with things I see and use in everyday applications. This class helped me see computer graphics as a combination of **programming, mathematics and visual representation**, rather than just drawing pictures.
