
Reflection – CSC360 Session 1



Within the first class, I learned the fundamentals of Computer Graphics. The first surprising thing was that Computer Graphics is not only about designing or creating graphics. By learning the course, I discovered that there are many things to consider in order to make one single picture.



I learned that we can store the digital image as pixels, where each pixel has a particular value. By putting pixels in column and row, we can say that the image is stored in the form of a matrix. Each pixel in the matrix contains the information about the particular spot in the image. For example, an RGB value. This knowledge allows us to understand how the computer stores and processes images.



The second thing that I learned is raster and vector graphics. Raster graphics are formed by pixels, while vector graphics use mathematical representations. Raster graphics are suitable for image editing, whereas vector graphics are good for logos and illustrations. Moreover, the raster graphics will have an apparent pixel structure when we enlarge them, while it will not happen to vector graphics. I personally like the explanation of the differences between these two kinds of graphics because I never considered how pixels affect pictures.



Moreover, the third interesting thing that I learned is Java 2D Graphics. In particular, I learned the concept of JFrame, JPanel, Graphics Context. From the first two terms, I understood that JFrame is a frame for an application, while JPanel is the panel for drawing. The Graphics Contexts give access to the drawing tools. I think that the main knowledge that I gain from this topic is the basis of creating Graphics in Java.



The last interesting thing that I learned is Geometric Transformations such as Translation, Scaling, Rotation. These transformations allow changing almost any visual representation of data manually or automatically. For example, we can use Rotation to rotate some object around a point, while Scaling changes its size. The translation is used to shift the position of an object. From this lecture, I learned how we can apply these transformations and for what tasks they can be used. Since translating or rotating objects can be applied in many places, such as computer games.



This class also included interesting tasks, such as drawing the line, perpendicular lines relative to a given one, and the intersection point of two lines. I believe that this topic is essential to the course because it shows that graphics are highly dependent on mathematics. We can see how coordinates, geometry, and calculation help to create and represent objects in a computer graphics way. It was also fun for me to solve and understand how we can find these elements mathematically.



Finally, we also learned Git and SSH. I learned that the first tool is suitable for version control, while the second one is used to make the connection between the computer and some remote repository.



In summary, This class allowed me to look at the Computer Graphics course more thoroughly. I realized that Computer Graphics is not only about creating images but also about representing them inside the computer. To do so, we need to learn about pixels, mathematical representations of objects, and even the basics of programming languages.
