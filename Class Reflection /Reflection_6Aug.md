
Reflection – CSC360 Session 1

In the first class, I learned about the basic concept of Computer Graphics. Before this class, I thought computer graphics was mainly about creating or designing images. But after learning about it, I understood that there is also a lot of information and processing happening behind an image.

I learned that a digital image can be represented using pixels. These pixels are arranged in rows and columns, which can be considered as a matrix. Each pixel contains some value that gives information about that part of the image. For a colour image, the values can represent RGB colours. This helped me understand how a computer can store and work with an image.

We also learned about raster and vector graphics. Raster graphics are made up of pixels and are commonly used for photographs. When a raster image is enlarged too much, the pixels can become visible and the image may lose its quality. Vector graphics are based on shapes and mathematical information. They are useful for things like logos, diagrams and other drawings. I found this difference useful because earlier I did not think much about how different types of images are represented.

Another topic I learned was Java 2D graphics. We discussed JFrame, JPanel and the Graphics Context. I understood that JFrame is used for the main window, JPanel provides an area for displaying graphics, and the Graphics Context provides the tools for drawing. This gave me a basic idea of how graphics can be created using Java.

I also learned about geometric transformations such as translation, scaling and rotation. Translation is used to move an object, scaling changes its size, and rotation changes its direction or angle. The examples of moving a triangle and zooming helped me understand these concepts more easily because I could relate them to actual graphical applications.

The class also covered drawing lines, perpendicular lines and finding the intersection of two lines. I found this interesting because it showed me that mathematics and computer graphics are closely connected. Coordinates, shapes and calculations are important when creating and changing graphical objects.

We were also introduced to Git and SSH. I learned that Git is used to keep track of changes in code, while SSH is used for secure communication between computers.

Overall, this class helped me understand that Computer Graphics is not only about making images. It involves pixels, shapes, coordinates, mathematics and programming. I got a better idea of how these different concepts work together to create and modify graphics.
