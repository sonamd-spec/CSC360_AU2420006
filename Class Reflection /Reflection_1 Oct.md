1. String Immutability in Java

One topic that was interesting for me to learn was String immutability in Java. I found out that after a String object is created, the value of it cannot be changed. For instance, when trying to add " World" to a String "Hello", a new String with the value "Hello World" will be created instead of changing the original String.

As a result of my studies, I learned that the immutability allows Java to handle Strings safely and share them within the same application easily.

I can apply the concept because JavaFX uses Strings for buttons' names, labels, messages, and the other text elements of an application. Moreover, the topic helped me to get to know that even text elements are objects stored in variables.

2. Binary Data and Binary Objects

One more topic that attracted my attention was Binary data and binary objects. I learned that the computer stores and processes information in a binary system. Although we see text, images, and the other data, all of these are presented to us in a digital format processed by computers with 0 and 1.

A binary object stores digital data in a computer-readable format. It can be images or compiled programs.

As a result of my studies, I learned that the binary objects are what we see on the screen in images or text, but a computer reads it in a different way.

I can apply the concept in my projects because JavaFX uses different resources, such as images, that are stored digitally. Moreover, I can continue developing my understanding that any information presented to me is in a computer-readable format.

3. Binary Cracking

One of the topics that have sparked my interest was binary cracking. I have learned that the compiled version of a program is different from the source code developed by a programmer. We use a particular programming language to write code that we compile following specific rules.

As a result of my studies, I learned that the information that I see in the programs is different from the compiled version that runs them. I also became interested in studying further how programs work after being compiled.

4. Badges and Chips in User Interfaces

One of the topics that I have learned and would like to develop further is badges and chips in user interfaces. Before learning this topic, I thought about buttons, labels, and text fields when designing a user interface. However, using badges and chips provides a way to present short pieces of information visually and organize them on the screen.

As a result of my studies, I learned that the information in badges and chips can help to find relevant data when using an application. Moreover, using these objects in a user interface makes it more organized and better-designed.

I can apply the concept to my projects by incorporating elements that help the user to find the required information faster.

5. Images, Shields and GIFs

The usage of images, shields, and GIFs in software projects is another topic that sparked my interest. I have learned that in some cases, images help to convey more information than lengthy texts.

They are crucial to show the appearance of an application, and GIFs demonstrate how a program works. Shields are common in the README file of a GitHub repository to present information about a repository shortly. For instance, a shield can show what programming language and frameworks were used to develop a program.

As a result of my studies, I learned that documentation should be informative and easy to read. Using images and GIFs in a README file of a GitHub repository helps to present the main points of a project concisely and attractively. Moreover, I can use shields in my projects to provide more information about them.

6. Layout and Integer Values

Another topic that I have studied and would like to develop further is the use of integer values to describe the position and size of objects in a user interface. For instance, coordinates show the position of an item in a system that follows the coordinate system rules. Also, integer values help to describe the size of an item.

As a result of my studies, I learned that the position and size of objects in a user interface are vital to follow the basic layout principles. This topic also reminded me of computer graphics that we study in the Computer Graphics course. The topic helped me to realize that it is essential to consider the visual aspect and values that define the position and size of objects.

7. Connecting Programming with User Interfaces

The topics that were covered in this class showed how the different parts of an application work together. When developing an application, I often focused on using Java to develop the application. However, I realized that there are more things to consider when building a program than writing code. For instance, I should pay attention to storing the necessary objects as files, managing the data of an application, and presenting information to a user in an informative and visually appealing way.

For instance, in JavaFX, we use Java to build a user interface with buttons, labels, and the other objects. We can use Strings to write text and create buttons, labels, and the other objects with text on them. Images and GIFs also make the user interface more informative and visually appealing. The application should also be easy to use and navigate for a user. Thus, both the programming code and user interface are equally important parts of an application.
