## Understanding Trees



Sir also discussed the concept of trees. I had previously heard the term tree in programming, but the discussion today helped me to understand this concept better.



A tree is basically a data structure where items are organized in a hierarchy. The topmost item is referred to as the root, and other items are placed below it. Items placed below are commonly referred to as nodes. Each node can also have its own child nodes. In the example below, we have a tree with 5 nodes.



A



/ \



B C



/ \



D E



In this example, A is the root node, B and C are the child nodes of A, and D and E are the child nodes of B.



Therefore,



this discussion helped me to realize that a tree in programming is not actually a tree. A tree is simply a hierarchical representation of nodes.



## Drawing A Tree Vs Making A Tree By Coding



Another point that I found particularly interesting was the difference between simply drawing a tree and making a tree by coding.



When we draw a tree, we can simply draw whatever we like. We can decide which node goes where, and we can connect nodes however we like.



On the other hand,



when we make a tree by coding, we need to first define the tree structure. We need to define exactly what nodes are connected to what other nodes, and where exactly the nodes should be placed on the screen.



Therefore,



we can say that drawing a tree is about its visual appearance, whereas making a tree by coding is about defining its structure.

## JavaFX Project – Three Equations



We also discussed the JavaFX project, where the program needs to read three equations as input and needs to draw triangles using JavaFX.



I understood that the three equations will be provided as text, and that the program should process them before displaying the result on the screen. ## Planning Before Coding



Sir’s explanations helped me to understand the importance of planning before coding. We can’t just start coding when we don’t even know how the application should behave. We need to think about the problem statement, and about the different operations that the application may need to perform.
